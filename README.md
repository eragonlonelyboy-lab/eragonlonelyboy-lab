# Hi, I'm Eragon Lee 👋

Here's what nobody warns you about AI agents: they lie to your face and smile while doing it.

Not on purpose. An AI agent is the world's most confident intern. It'll swear the task is done (the write silently failed), tell you the page is updated (it isn't), read a 3,000-line file to find five lines (and bill you for all 3,000), and forget the correction you made on Tuesday by Thursday morning. Every time. With enthusiasm.

I'm a product and project manager. My whole job is shipping software people can actually trust. So when I started directing AI agents to build instead of writing every line myself, I hit that wall at full speed, and then I did the PM thing: stopped complaining, and built the tools that make the agents behave.

I don't type the code. I own the spec, the standard, and the receipts. Turns out you can run a swarm of AI agents like a team, as long as someone's willing to be the adult in the room.

That someone is a house of gods now. It's a whole thing.

## 🛠️ How I actually build

- **Product Owner, not a typist.** I run agents the way you run a good team: sharp spec, tight feedback, and nothing ships without evidence. The repos are the output. The judgment is the job.
- **Evidence over vibes.** Every tool carries a benchmark you can rerun and a page listing exactly where it fails. If I can't measure it, I'll tell you I can't, instead of inventing a number that sounds nice.
- **Windows-first, because someone has to be.** Most dev tools treat Windows like a rumor. I build there first, on purpose.
